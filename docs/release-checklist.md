# Static Website Release Checklist

- [ ] Check relative paths from the published root.
- [ ] Confirm `.nojekyll` and required assets are present.
- [ ] Check links, images, and downloadable files.
- [ ] Verify semantic headings, page title, and metadata.
- [ ] Test navigation without a mouse.
- [ ] Check the layout at a narrow mobile width.
- [ ] Inspect the published site after deployment.
- [ ] Revert promptly if the release breaks key navigation or downloads.
