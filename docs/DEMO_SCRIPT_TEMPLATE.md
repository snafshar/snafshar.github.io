# Project demo script

1. **Context:** explain the problem in one minute.
2. **Baseline:** show the starting point or limitation.
3. **Walkthrough:** demonstrate the core user journey.
4. **Evidence:** show tests or measured output.
5. **Trade-offs:** state limitations and decisions.
6. **Next steps:** identify the most valuable improvement.

Keep the demo reproducible and prepare a fallback for network or environment issues.
