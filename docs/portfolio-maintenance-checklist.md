# Portfolio Maintenance Checklist

- [ ] Verify project links and live demos.
- [ ] Ensure project descriptions distinguish production features from prototypes.
- [ ] Check CV download links and document dates.
- [ ] Add meaningful alt text to informative images.
- [ ] Check keyboard navigation and visible focus states.
- [ ] Test mobile, tablet, and desktop widths.
- [ ] Check for broken links and browser-console errors.
- [ ] Keep contact details intentional and avoid publishing private information.
- [ ] Preview changes before merging into `main`.
